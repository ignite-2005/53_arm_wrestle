# Arm Wrestle Showdown — VibeCoding Lab

Personal fixed copy of the assigned starter repository [SETAPESU26/53_arm_wrestle](https://github.com/SETAPESU26/53_arm_wrestle).

## Run locally
```bash
python -m pip install -r requirements.txt
python main.py
```
Alternate **Left Arrow** and **Right Arrow** to push. Press **R** after the match ends to restart.

## Bug fix and requested features
1. Fixed the inverted player push direction: alternating inputs now move the arm toward the player's `-100` winning threshold.
2. Added a repeating 2-second AI power surge and 4-second cooldown with different force levels.
3. Added visible AI surge/cooldown states, counter-window, low-stamina and exhaustion feedback.
4. Added a short counter-surge window. A Right-arrow press during the cooldown window grants a temporary 2x push bonus and faster stamina recovery.
5. Uses elapsed time for the AI cycle and stamina recovery.
